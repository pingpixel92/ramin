# وب‌سایت شخصی رامین جلادت

سایت شخصی رامین جلادت — معلم زبان انگلیسی و مدیر دپارتمانت زبان مجموعه مدارس سلام.

**آدرس:** <https://ramin-djaladat.kdns.fr>

## ساختار پروژه

```
├── index.html        صفحه‌ی اصلی (دوزبانه: فارسی / انگلیسی)
├── 404.html          صفحه‌ی «پیدا نشد»
├── CNAME             دامنه‌ی سفارشی
├── robots.txt        راهنمای خزنده‌ها
├── sitemap.xml       نقشه‌ی سایت
├── site.webmanifest  مشخصات PWA
└── assets/
    ├── css/          استایل‌ها
    ├── js/           اسکریپت‌ها (تعویض زبان، تم، فلش‌کارت واژه و…)
    ├── fonts/        فونت‌های میزبان‌شده (استعداد و Fraunces)
    └── img/          آیکون و تصویر اشتراک‌گذاری
```

سایت با HTML/CSS/JS خالص نوشته شده و به هیچ فریم‌ورک، کتابخانه یا سرویس بیرونی وابسته نیست — حتی فونت‌ها هم روی همان هاست سرو می‌شوند تا در همه‌ی شبکه‌ها سریع باشد.

## اجرای محلی

همین پوشه را با هر وب‌سرور استاتیکی باز کنید؛ مثلاً:

```bash
python3 -m http.server 8000
```

## انتشار

گیت‌هاب پیجز از شاخه‌ی `main` منتشر می‌شود و دامنه‌ی سفارشی آن از طریق فایل `CNAME` تنظیم شده است.
